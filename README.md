# Sales Dashboard

Projeto desenvolvido em **Microsoft Power BI** com o objetivo de demonstrar o fluxo completo de um projeto de **Business Intelligence**, desde a preparação dos dados até a construção de um dashboard interativo para análise de vendas.

O projeto contempla as etapas de **ETL**, **modelagem relacional**, **criação de medidas em DAX** e **visualização de indicadores**, seguindo boas práticas utilizadas em projetos de BI.

---

# Tecnologias

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Microsoft Excel

# Processo de ETL

A preparação dos dados foi realizada utilizando **Power Query**, contemplando etapas como:

- Importação de múltiplas tabelas;
- Tratamento de valores nulos;
- Padronização de colunas;
- Conversão de tipos de dados;
- Limpeza de inconsistências;
- Criação de colunas auxiliares;
- Construção da Tabela Calendário;
- Carregamento dos dados para o modelo.

# Modelagem de Dados

Após a etapa de transformação, foi construída uma modelagem relacional entre as tabelas, utilizando boas práticas para garantir consistência e desempenho das análises.

O modelo contempla:

- Relacionamentos entre tabelas;
- Modelo em Estrela (Star Schema);
- Tabela Calendário;
- Chaves de relacionamento.
